# Nift

> Nift is a customer-gifting / acquisition platform: businesses send "thank-you" gifts that let their customers discover and try new brands, restaurants, and services. Partners integrate the Nift gift-redemption ("card flow") into their apps via SDKs, and use a server-side Partners API for customer status and deletion. Proprietary AI matches each recipient to gift options.

## APIs
- [Nift Partners API](https://github.com/nift-sdks/nift-flow-sdk-docs): OAuth2 server-side API for customer status and deletion (base https://www.gonift.com).

## Specs
- [OpenAPI (reconstructed)](openapi/nift-partners-openapi.yml): Partners API — getCustomerStatus, createCustomerDeletions.

## SDKs
- [Web SDK](https://github.com/nift-sdks/nift-flow-sdk-docs/blob/main/docs/sdk/web.md): NiftWebSDK, CDN embed with an in-page modal card flow.
- [Android SDK](https://github.com/nift-sdks/nift-flow-sdk-docs/blob/main/docs/sdk/android.md): NiftCardFlowFragment / NiftCardFlowScreen (com.nift:nift-card-flow).
- [iOS SDK](https://github.com/nift-sdks/nift-flow-sdk-docs/blob/main/docs/sdk/ios.md): NiftCardFlowView (Swift Package Manager).
- [React Native SDK](https://github.com/nift-sdks/nift-flow-sdk-docs/blob/main/docs/sdk/react-native.md): @nift-sdks/nift-card-flow-react-native.

## Operational notes
- No pricing page, no status page, no changelog, no roadmap, and no published rate limits — see plans/, lifecycle/ and rate-limits/ artifacts.
- No /.well-known surface of any kind (security.txt, oauth-authorization-server, api-catalog, agent card all 404).
- No MCP server, no webhooks and no event/AsyncAPI surface. mcp/nift-mcp.yml is a derived CANDIDATE tool list, not a shipped agent surface.
- API access is provisioned by Nift: OAuth client_id/client_secret, SDK clientId and partner referral code are all issued by Nift, not self-serve.
